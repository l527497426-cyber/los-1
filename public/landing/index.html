LosDesign

界面是有层级、有方向、有空间关系的数字空间。
所有动效和交互反馈，都服务于在这个空间里建立感知。

这是 Loszo 的个人设计判断框架，提炼自我反复使用的三层判断方式 —— 空间语义 → 量级 → 实现底线。装到 Claude / Cowork 里之后， 所有 motion、interaction、spatial UI 的判断都会先套这套视角， 而不是默认沿用通用 motion-design 套路。

Install 下载 los-design.skill

下载后把文件拖进 Cowork 的对话窗口，会弹出「Save skill」按钮一键安装。
Claude Code 用户：解压后放进 ~/.claude/skills/ 即可。
